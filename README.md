### Как запускать код
1. Создайте папку `build` в корне репозитория
2. Выполните
`cmake -B build -S .`
`cmake --build build`
4. После в папке build у вас должен появиться файл `hw-01-tic-tac-toe`
5. Для тестирования из папки `tests` выполните `python3 run_tests.py  ../build/hw-01-tic-tac-toe .` В выводе должна появится информация о пройденных тестах

**Note:** после каждого изменения исходных файлов (main.cpp) необходимо перекомпилировать программу с помощью `cmake --build build`

### Условие

Реализуйте консольную игру «Крестики-нолики» для двух игроков.

В игре есть игровое поле размером `3 × 3`. Первый игрок играет за `X`, второй — за `O`. Игроки по очереди выбирают свободную клетку поля. Игрок, который первым поставил три своих символа подряд по горизонтали, вертикали или диагонали, побеждает.

Если все клетки поля заняты, но ни один игрок не собрал три символа подряд, игра заканчивается ничьёй.

- Пока есть свободные ячейки и ни один игрок не собрал 3 символа подряд, программа запрашивает ввод у текущего игрока в формате ```Player X:```, если сейчас ход игрока ```X```, или ```Player O:```, если сейчас ход игрока ```O```

- Гарантируется, что входные данные корректны за двумя исключениями: пользователь может попытаться сделать ход в уже занятую ячейку, либо ввести некорректный номер ячейки (например 15)

- Для пользователя ячейки пронумерованы в таком порядке:
```
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```

При этом, в вашем внутреннем представлении, может быть удобнее нумеровать ячейки с нуля, то есть
```
 0 | 1 | 2
---+---+---
 3 | 4 | 5
---+---+---
 6 | 7 | 8
```

- За исключением двух вышеописанных исключений можно считать ввод корректным и не обрабатывать другие случаи, такие как конец ввода, ввод строки вместо числа и прочие.

- Строка ```<X/O>``` в условиях задачи означает, что в этом месте стоит символ ```X```, если текущий игрок ```X``` или ```O```, если текущий игрок ```O```.

- Программа запрашивает ввод у пользователя в формате ```Player <X/O>:``` до тех пор, пока пользователь не введёт корректный номер ячейки.

- До тех пор, пока игра не завершилась (победой одного из игроков или ничьей), программа сначала выводит текущее игровое поле, затем запрашивает у пользователя ввод. Формат поля:

```
 . | . | .
---+---+--
 . | . | .
---+---+--
 . | . | .
```

Точки обозначают свободную ячейку. По ходу игры точки заменяются на ```X``` или ```O``` в зависимости от ходов игроков.

- После очередного хода необходимо проверить, не победил ли игрок и не завершилась ли игра ничьей. Если игра завершилась победой одного из игроков, необходимо вывести ```Player <X/O> won```, а затем всё поле и завершить программу. Если игра завершилась ничьей, необходимо вывести ```Tie```, а затем всё поле и завершить программу.

- Каждая строка выводится с переносом строки

### Советы

- Внутри программы поле должно храниться в `std::vector<char>` размером `9`.

- Для вывода поля, можно использовать ```std::println``` и raw string literals (можете просто скопировать следующую строчку и использовать её у себя в программе для вывода, только не забудьте поменять имя переменной в которой хранится ваше поле):

```
std::println(
R"( {} | {} | {}
---+---+---
 {} | {} | {}
---+---+---
 {} | {} | {})",
            field[0], field[1], field[2], field[3], field[4], field[5], field[6], field[7], field[8]);
```
- Для ввода номера ячейки может быть удобнее использовать цикл ```do while``` вместо обычного ```while```

- Для определения победителя и проверки на 3 одинаковых символа в ряд может быть удобно использовать созданный заранее вектор с перечисленными полями для проверки, чем писать кучу ```if``` на каждую строку/столбец/диагональ:

```

    {0, 1, 2},
    {3, 4, 5},
    {6, 7, 8},
    {0, 3, 6},
    {1, 4, 7},
    {2, 5, 8},
    {0, 4, 8},
    {2, 4, 6}
};
```

и затем проверять с помощью цикла

```
bool win {false};
for(const auto& line : wins){
    if((field[line[0]] == current_player) && (field[line[1]] == current_player) && (field[line[2]] == current_player)){

    }
}
```
